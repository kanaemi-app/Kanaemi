# かなで打った数は、読みにそれを受ける置き場所を書いた項目だけが受ける

状態：採用

## 背景

数値の項目の読みの置き場所は、数字の並びだけを受ける。「さんだんかい」のように数をかなで打つと、数値の項目には当たらない。かなで打つ数を含む語は、数ごとに項目を書くしかない。公式の辞書も、「さんかい　三回」のような項目を数ごとに持っている。

今ある数値の項目の読みは、数字で打つときの読みとして書かれていて、数をかなで読んだときの発音とは限らない。`{}か` は「3か」で3日を出すが、3日の読みは「みっか」である。公式の辞書で、今ある置き場所がかなの数も受けるとして試すと、約 39 万の読みのうち約 1.2 万が数値の項目に当たる。その中には「さんか」（参加）から「三歌」、「ごはん」から「五番」、「せんごは」（戦後派）から「1005馬」のように、数ではない語が多く含まれていた。

## 決定

数値の項目の読みに、かなで打った数を受ける置き場所を、数字を受ける置き場所とは別に書けるようにする。かなで打った数は、その置き場所を書いた項目だけが受ける。関数には、受けた数を数字に直して渡す。

## 検討した他の案

- 今ある読みの置き場所が、かなの数も受けるようにする：今ある項目の読みは数字で打つときの読みで書かれているので、数ではない語に誤った候補が出る。
- かなの数から作った候補を、ほかの候補より後ろに並べて、今ある置き場所で受ける：辞書にない語を打つと、誤った候補が先頭に出る。誤った候補の数も減らない。
- 関数に、打ったかなのまま渡す：数の書き方の関数と利用者の関数が、どれもかなの数を読めるように直す必要がある。

## 結果

- 「さんだんかい」のような語は、数ごとにではなく、1 行で書ける。
- 今ある辞書が出す候補は変わらない。かなで打つ数を受けたい項目は、受ける置き場所で書き直す。
- 関数には数字しか渡らないので、関数は、数をかなで打ったか数字で打ったかを区別できない。
