# 関数は、置き場所を埋める値をいくつも返せる

状態：採用

## 背景

「3段階・３段階・三段階」を候補に出すには、数の書き方ごとに 1 行ずつ書く。公式の辞書も、`{}えん` に `{half-num}円`・`{wide-num}円`・`{grouped-num}円` を別の行で持っている。語ごとに同じ行を書き並べることになり、利用者が手で書くと面倒で、書き漏らしもする。

置き場所は、名前で呼ぶ関数で埋めるという一つの決まりで書く（`20261006-write-placeholders-as-named-functions.md`）。いくつもの書き方を一度に出すために、関数を呼ぶほかの決まりを置き場所に足したくない。

確定履歴・よく選ぶ候補・出さないことにした語は、項目に付く。いくつもの値を同じ項目から出すと、どの値を選んだか、どの値を出さないかが項目だけでは分からない。

## 決定

関数は、置き場所を埋める値を 1 つだけでなく、いくつも返せる。値ごとに候補を作る。

関数は値ごとに、その値だけを返す引数を添えられる。記録は、置き場所をその引数で呼ぶように書き直した項目に付く。引数を添えない値の記録は、元の項目に付く。

## 検討した他の案

- 特別な名前の置き場所を、辞書を読むときに書き方ごとの行に広げる：関数を呼ぶのとは別の決まりが置き場所に増え、名前を 1 つ関数に使えなくなる。
- 記録を、何番目の値かに付ける：出さない行に番号を書く書き方が要る。関数が返す並びを変えると、記録が別の値に効く。
- 今のまま、書き方ごとに行を書く：語ごとに同じ行を書き並べる手間が残る。

## 結果

- 数のよく使う書き方をまとめて返す関数を、組み込みの関数として持てる。利用者も、いくつもの値を返す関数を書ける。
- 引数を添えた値は、選んだ書き方がほかの数を打ったときにも効き、値ごとに出さないことにできる。出さない行は、引数で呼ぶ置き場所の、ふつうの項目の書き方で書ける。
- 引数を添えない値は、記録も出さないことも、その行の値すべてにまとめて効く。
- いくつもの値を返す置き場所が 1 行に 2 つ以上あれば、値の組み合わせがすべて候補になる。
