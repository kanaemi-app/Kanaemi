# 利用者の打った語を含むファイルは、設定のフォルダの外にも置ける

状態：採用

## 背景

ユーザーカスタム辞書とよく選ぶ候補の記録には、利用者が打った語が入る。[ユーザーカスタム辞書を、人が編集できる追記型のテキストにする](20261003-keep-the-user-custom-dictionary-as-editable-text.md) は、ユーザーカスタム辞書を同期フォルダに置き、複数の端末で使うことを想定している。よく選ぶ候補の記録も、打った語を守れる場所に置きたいことがある。

ところが、どちらも設定のフォルダの中にしか置けない。設定のフォルダには、利用者が別に管理している設定ファイルや、端末ごとに持つ並べ替えのモデルも入っている。

## 決定

- ユーザーカスタム辞書とよく選ぶ候補の記録は、それぞれのファイルの場所を設定ファイルで指定できる。指定しなければ、設定のフォルダの中に置く。
- 設定のフォルダのほかのファイルの場所は変えられない。

## 検討した他の案

- 同期フォルダなどへのシンボリックリンクにして、Kanaemi はリンクをたどって書く：ファイルを書くどの部品も、置き換えるときにリンクを解かなければならない。1 つでも漏れると、リンクがふつうのファイルに置き換わり、何も知らせずに指定した場所から外れる。Windows ではリンクを作るのに権限も要る。
- 設定のフォルダの場所を変えられるようにする：設定ファイルと端末ごとに持つものまで一緒に動く。設定のフォルダの場所は、その中の設定ファイルには書けない。
- 打った語を含むファイルをまとめて置くフォルダを 1 つ指定する：ユーザーカスタム辞書は端末をまたいで同じにし、よく選ぶ候補の記録は端末ごとに持つ、という置き方ができない。

## 結果

- これらのファイルを書き換えるときは、そのファイルと同じフォルダの中で置き換える。設定のフォルダとは別のボリュームにあっても書き換えられる。
- 指定したフォルダが、ない・読めない・書けないことがある。IME はそのあいだも動き、設定アプリはそれを利用者に知らせる。
