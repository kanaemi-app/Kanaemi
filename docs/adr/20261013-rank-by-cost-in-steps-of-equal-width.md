# 並べ替えのモデルは、候補のコストを一定の幅の段で見る

状態：採用

## 背景

辞書のコストは、使われる頻度の対数である（e 倍ごとに 100）。並べ替えのモデルはコストを 2 を底とする対数の幅で見ていたので、1024〜2047 の幅は頻度で約 2 万倍の差をまとめて一つに見ていた。たいていの候補はこの幅に入るので、2 番目より後ろの候補は、コストではなく表層の特徴で並んでいた。公式の辞書とモデルで調べると、モデルが最も頻度の高い語を 1 位にしなかった読みの 99.9% で、1 位の語と最も頻度の高い語が同じ幅に入っていた（対象 794 と 大賞 1022 など）。幅の境目では重みが大きく跳び、512〜1023 の幅が +3.5、1024〜2047 の幅がほぼ 0 だった。

## 決定

並べ替えのモデルは、候補のコストを一定の幅の段で見る。細かい段と広い段の両方を特徴にする。

## 検討した他の案

- コストをそのまま数として特徴にする：重みと特徴の有無を足し合わせる今の形に、値を掛ける特徴が入る。学習する側も変わる。コストと頻度の関係を直線と決めてしまう。
- 2 を底とする対数の幅を細かくする：コストはすでに対数なので、対数をもう一度取ると、安い語ほど段が細かく、よく使われる語どうしの差ほど見えなくなる。
- 候補どうしのコストの差を特徴にする：特徴が、ほかの候補に左右される。今は 1 つの候補だけから特徴を作るので、学習する側の例の作り方まで変わる。

## 結果

- 頻度の差は、どのコストでも同じ細かさで見える。
- 特徴の作り方が変わるので、モデルの形式の版を上げ、学習し直す。
