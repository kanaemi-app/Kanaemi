# 登録する語の数は、置き場所にした形を見て選んだときだけ置き場所にする

状態：採用

## 背景

数値の項目を足すには、`{kanji}段階` のような置き場所を打つ必要がある。置き場所の書き方と関数の名前を知らなければ書けない。読み「さんだんかい」で「三段階」と打てば、それだけで `{kana}だんかい	{kanji}段階` にすることはできる。

ただ、読みの数を書いている語が、数の語とは限らない。「いっしょ」の「一緒」を置き場所にすると `{kana}しょ	{kanji}緒` になり、「にしょ」で「二緒」が出る。「きゅうしゅう」の「九州」、「しき」の「四季」、「じゅうぶん」の「十分」も同じである。かなの数を受ける項目から作った候補は後ろに並ぶので、登録した「一緒」そのものも、「いっしょ」の候補の後ろに回る。数の語かどうかは、語を知っている人にしか分からない。

## 決定

登録する語が読みの数を書いていても、置き場所を打っていなければ、打ったままの語として登録する。数を置き場所にするのは、設定アプリで、置き場所にした形と、いくつかの数で出る候補を見た人が、それを選んだときだけにする。

かなの数を受ける置き場所から作った候補は、どの辞書のものでも、同じ読みのほかの項目から作った候補より後ろに出す。選んで足した語はユーザーカスタム辞書に入り、ユーザーカスタム辞書は辞書の一覧の先頭にある。「さんかく」の「三角」を置き場所にすると、そのままでは「ごかく」で「五角」が「互角」より先に出るからである。

## 検討した他の案

- その場の登録でも、読みの数を書いた語を自動で置き場所にする：「一緒」のような語が、ほかの数にも誤った候補を出し、語そのものも後ろに回る。登録の場面には、置き場所にした形を見せる場所がない。
- その場の登録で、置き場所にするか尋ねる：登録の場面は打っている文字列のほかに見せる場所がなく、尋ねるためのキーも要る。
- 数のあとに助数詞が続くときだけ自動で置き場所にする：助数詞の一覧を持つことになり、「一番」と「一緒」のように同じ形で分けられない語が残る。

## 結果

- 置き場所の書き方を知らなくても、設定アプリで数値の項目を足せる。
- その場の登録では、置き場所を打たない限り、数値の項目にならない。「さんだんかい」をほかの数にも効かせるには、設定アプリで足すか、`{kanji}段階` と打って登録する。
- 数ではない語が置き場所になるのは、置き場所にした形を見た人が選んだときだけになる。
