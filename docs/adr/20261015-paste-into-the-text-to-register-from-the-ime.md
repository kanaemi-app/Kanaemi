# 登録する文字列への貼り付けは、IME がクリップボードを読んで行う

状態：採用

## 背景

登録したい語は、ほかの所から写してくることが多い。登録の場面は入力欄の未確定文字列の中にあり、アプリに貼り付けさせると、貼った文字列は未確定文字列の外の入力欄に入る。

## 決定

登録する文字列を打っているときに貼り付けのキーを押すと、IME がクリップボードの文字列を読んで、登録する文字列に入れる。

## 検討した他の案

- 貼り付けのキーをアプリに渡す：アプリが未確定文字列の外に貼り、登録する文字列には入らない。
- アプリのメニューからの貼り付けを受け取る：貼るのはアプリで、IME には何を貼ったかも届かない。

## 結果

- メニューからの貼り付けは、登録する文字列には入らない。
- アプリが自分の貼り付けに使うキー（macOS の Cmd+V）は、貼り付けのキーにできない。アプリは IME にキーを渡さずに、あるいは IME が受け取っても、未確定文字列の外に貼る。
- IME がクリップボードを読むのは、貼り付けのキーを押したときだけ。そのキーの処理は、クリップボードを持つプログラムの答えを待つ。
