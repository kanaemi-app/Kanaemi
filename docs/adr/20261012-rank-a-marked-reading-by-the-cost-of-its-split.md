# 送り仮名を示した読みでは、示した区切りで出した形のコストで候補を並べる

状態：採用

## 背景

送り仮名を示した読み（`き*て`）では、送り仮名で区切って出した候補を、読み全体の語より先に並べる。ところが、同じ表記を読み全体の語（`きて 来て`）からも出せると、その語のコストが候補のコストになることがあった。読み全体の語のコストは、送り仮名を示さずに打つ人のためのものである。そのため、示した区切りでは後ろにあるべき語（来て）が、区切りで出した語（着て）より先に並んでいた。

## 決定

送り仮名を示した読みで、示した区切りで出せる候補は、その出し方のコストだけで並べる。読み全体の語のコストは、区切りで出せない候補にだけ使う。

## 検討した他の案

- 辞書の側で、読み全体の語のコストを上げる：送り仮名を示さずに打つ人の並びまで変わる。
- 送り仮名を示した読みでは、読み全体の語を候補にしない：区切りに合う語が辞書にないとき、候補が出なくなる。

## 結果

- 送り仮名を示して打つ並びと示さずに打つ並びを、辞書は別々のコストで決められる。
