# 表記の置き場所

辞書の項目の表記のうち、変換のたびに関数を呼んで埋める部分。読みの数を好きな書き方で書ける（[数値変換](numeric-conversion.md)）ほか、今日の日付のように、変換するたびに値の変わる語も書ける。

## 書き方

```
{位置:関数 引数}
```

- 位置：関数に渡す変換元を選ぶ。数字なら、読みの数を前から 0, 1, 2 … と数えたその番号の数。空なら次の数（位置を省いた置き場所だけで数える）。`-` なら読み全体。
- 関数：呼ぶ [関数](functions.md) の名前。名前が空なら、変換元をそのまま返す。名前に `:`・スペース・`{`・`}`・`\` は使えない。
- 引数：名前の後ろの最初のスペースより後ろ、`}` の前までの文字列。スペースがなければ、引数はない。`{`・`}`・`\` は `\{`・`\}`・`\\` と書く（[エスケープ](text-dictionary.md#エスケープ)）。
- `:` のない `{関数 引数}` は、`{:関数 引数}` と同じ。

| 書き方 | 意味 |
| --- | --- |
| `{}` | 次の数をそのまま書く |
| `{kanji}`・`{:kanji}` | 次の数を `kanji` で書く |
| `{1:kanji}` | 2 つ目の数を `kanji` で書く |
| `{1:}` | 2 つ目の数をそのまま書く |
| `{num}` | 次の数を、半角・全角・漢数字のそれぞれで書く（[いくつもの書き方](numeric-conversion.md#いくつもの書き方)） |
| `{num kanji daiji}` | 次の数を、`kanji` と `daiji` のそれぞれで書く |
| `{-:}` | 読み全体をそのまま書く |
| `{-:date %Y-%m-%d}` | `date` に、読み全体と `%Y-%m-%d` を渡す |

```
{}がつ{}にち	{-:date %Y}年{kanji}月{kanji}日
{}がつ{}にち	{-:date %Y}年{0:kanji}月{1:kanji}日
きょう	{-:date %Y-%m-%d}
{kana}だんかい	{num}段階
```

表記の位置は、読みの [数の置き場所](numeric-conversion.md#数値の項目) を、名前によらず前から数える。

次の置き場所のある行は無効。

- 位置の番号が、読みの数の置き場所の数以上。
- 位置を省いた置き場所が、読みの数の置き場所より多い。
- 位置が、数字・`-`・空のどれでもない。

### 読みの置き場所との違い

置き場所は、読みにも表記にも `{名前}` の形で書き、どちらも名前で選ぶ。選ぶものが違う。

| | 名前で選ぶもの | 名前が空（`{}`） |
| --- | --- | --- |
| 読み | 打った読みのうち、何を数として受けるか | 数字の並びを受ける |
| 表記 | 受けた数や読みを、どの関数で書くか | 変換元をそのまま書く |

読みの名前は、数の置き場所の名前（`kana` など）だけで、関数の名前ではない。読みの `{kana}` は関数 `kana` を呼ばず、表記の `{kanji}` は数を受けない。読みには位置と引数も書かない。

## 埋め方

候補を作るとき、置き場所ごとに関数を呼び、その戻り値で置き場所を埋める。関数が値をいくつも返したときは、値ごとに候補を作る。いくつもの値を返す置き場所が 1 行に 2 つ以上あれば、値の組み合わせのそれぞれが候補になる（`{num}月{num}日` は 12月3日・12月３日 … 十二月三日）。書き方をそろえたいときは、`{kanji}月{kanji}日` のように書き方ごとの行を書く。

- 関数には、変換元と引数を渡す。変換元は打ったままで、数字を半角にするなどの変換はしない。ただし、かなで打った数（`{kana}` が受けた数）は、半角の数字に直して渡す（さん → 3）。
- 関数がないとき、失敗したとき、文字列も文字列のリストも返さなかったときは、その項目から候補を作らない。

## 記録

置き場所のある項目から作った候補の確定履歴・よく選ぶ候補・出さないことにした語は、埋めた値ではなく項目に付く。埋めた値が変わっても、同じ項目には同じ記録が効く。

関数が値をいくつも返したときは、値ごとに次の項目に付く。

- 関数がその値に、その値だけを返す引数を添えたときは、置き場所をその引数で呼ぶように書き直した項目。`{}こ	{num}個` の 一個 は `{}こ	{num kanji}個` に付くので、`1こ` で 一個 を選ぶと、`2こ` でも 二個 が先に出る。出さないことにすると、`!{}こ	{num kanji}個` を書く。
- 添えなかったときは、元の項目。その行の値すべてに、まとめて効く。

## 辞書登録

登録する文字列は、次のどれかとして登録し、置き場所を埋めたものを確定する。

- 置き場所を含む文字列は、そのまま置き場所のある項目として登録する。読みの数は、数字なら `{}`、かななら `{kana}` にする。
- それ以外の文字列と、置き場所として読むと無効な行になる文字列は、打ったままの読みと文字列で登録する。読みの数を書いている文字列（読み「さんだんかい」で「三段階」）も、打ったままの語になる。数を置き場所にした語は、[設定アプリ](settings-app.md#登録した語) で選んで足す。
