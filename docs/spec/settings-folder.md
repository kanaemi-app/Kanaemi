# 設定のフォルダ

IME と設定アプリが読み書きするファイルを置くフォルダ。

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Application Support/kanaemi/` |
| Windows | `%APPDATA%\kanaemi\` |
| Linux | `$XDG_CONFIG_HOME/kanaemi/`（なければ `~/.config/kanaemi/`） |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `config.toml` | [設定ファイル](settings.md) |
| `custom.tsv` | [ユーザーカスタム辞書](text-dictionary.md#ユーザーカスタム辞書)（[設定ファイル](settings.md#打った語を含むファイルの場所) で、ほかの場所に置ける） |
| `dictionaries/` | 辞書のファイル。中にフォルダを作ってもよい |
| `romaji/` | [ローマ字の表](romaji-table.md) のファイル |
| `functions/` | [利用者の関数](functions.md#利用者の関数) の Luau のファイル |
| `ranking.model` | [並べ替えのモデル](ranking-model.md)（なくてもよい） |
| `selections.tsv` | [よく選ぶ候補](conversion.md#よく選ぶ候補) の記録（IME が作る。[設定ファイル](settings.md#打った語を含むファイルの場所) で、ほかの場所に置ける） |

- IME は、設定のフォルダと `config.toml` がなければ作る。
- 利用者の打った語を含むファイル（ユーザーカスタム辞書・`selections.tsv`）は、IME と設定アプリが作るとき、持ち主だけが読み書きできるようにする。
- いくつもの IME のプロセスと設定アプリが同じときにユーザーカスタム辞書や `selections.tsv` を書いても、ほかが書いたものを消さない。IME は、ほかが書いているあいだ長く待たず、書けなかった語や選択は次の機会に書く。そのあいだも、語はメモリでは効く（[キーを処理するあいだは、ディスクにもロックにも長く待たない](../adr/20261009-do-not-wait-on-the-disk-or-a-lock-while-handling-keys.md)）。
- ユーザーカスタム辞書や `selections.tsv` を書くときに使う作業用のファイルは、そのファイルと同じフォルダに作る。ほかの場所に置いても、そのフォルダの外には書かない。
- 閉じ込められたアプリ（AppContainer など）の中の IME は、利用者の打った語を含むファイルを読みも書きもしない。そのアプリの中でも、辞書登録と削除はできる（[Windows ではユーザーデータの書き込みを別プロセスに任せる](../adr/20261003-write-user-data-from-a-separate-process-on-windows.md)）。

IME のログは、設定のフォルダの外に書く。[設定アプリ](settings-app.md#そのほか) で見られる。ログは大きくなると新しく書き始め、それまでのログをいくつか残す。

ログには、IME に届いたキーと、IME がそれに返したものを書く。利用者の打った文字（読み・候補・確定した文字列・文字のキー）は、ひらがな・カタカナ・漢字・英字・数字の種類だけを残して伏せる。ファイルの場所は、ホームフォルダを `~` と書く。ログを不具合の報告に付けても、打った語や利用者の名前は伝わらない。ただし、[利用者の関数](functions.md#利用者の関数) が `print` で出したものは、そのまま書く。

## 読み直し

IME は、入力欄にフォーカスが入るとき、変わったファイルだけを読み直す。

- `config.toml` が変わっていれば、設定を読み直す。
- 使っている辞書のファイルやユーザーカスタム辞書を足した・消した・書き換えたとき、ユーザーカスタム辞書の場所が変わったとき、辞書の一覧が変わったとき、`ranking.model` が変わったときは、それを反映する。打っている途中の確定履歴と、まだ書いていない記録は引き継ぐ。
- `selections.tsv` が変わったときは、読み直したものの上に、まだ書いていない選択を重ねる。ほかで書かれた選択も、まだ書いていない選択も残る。消されたときは、まだ書いていない選択も捨てて、空から始める。
- `functions/` のファイルを足した・消した・書き換えたときは、関数を読み直す。
