# 数値変換

数を含む読みを、数の書き方を選べる候補に変換する（`１こ` → 1個・１個・一個）。辞書には数の代わりに置き場所を書いた項目（数値の項目）を置き、変換のときに打った数で埋める。

## 読みの中の数

数は、読みの中で続いている数字の並び。半角と全角の数字のどちらでもよい。一つの読みにいくつあってもよい（`1がつ2にち` の 1 と 2）。

読みは数字からも始められる（`begin` を `;` に割り当てたとき、`;1ko` → 読み「１こ」）。数字が全角になるかは [ローマ字の表](romaji-table.md) による。

### かなの数

かなで打った数（`さんだんかい` の さん）は、読みに `{kana}` を書いた数値の項目だけが受ける。受けるのは、漢語の数詞（いち〜きゅう・じゅう・ひゃく・せん・まん・おく・ちょう・けい を組み合わせたもの）と、その音の変わった形（いっ・ろっ・はっ・じゅっ・じっ・びゃく・ぴゃく・ぜん など）。和語の数詞（ひと・ふた・みっ）と、れい・ぜろ は受けない。

## 数値の項目

[テキストの辞書](text-dictionary.md#置き場所のある語) の読みに数の置き場所を含む項目。数の置き場所は、名前で何を数として受けるかを選び、前から順に読みの数が入る。

- `{}`：数字の並びを受ける。
- `{kana}`：[かなの数](#かなの数) を受ける。

読みの置き場所の名前は関数の名前ではない。表記の [置き場所](placeholder.md) が関数を呼び、受けた数をどう書くかを選ぶ（[読みの置き場所との違い](placeholder.md#読みの置き場所との違い)）。

知らない名前の数の置き場所を読みに持つ行は無効。

```
{}こ	{}個
{}こ	{wide-num}個
{}こ	{kanji}個
{}がつ{}にち	{kanji}月{kanji}日
{kana}だんかい	{num}段階
```

数の読み方で後ろの音が変わる語は、読みを分けて書く（`{kana}ほん`・`{kana}ぼん`・`{kana}ぽん`）。

IME は、数の書き方として次の [組み込みの関数](functions.md#組み込みの関数) を持つ。どれも引数を使わず、変換元が数でなければ値を返さない。[`num`](#いくつもの書き方) の引数では、それぞれを表の名前で選ぶ。

| 名前 | `num` の引数 | 書き方 | 例（12） | 例（2026） |
| --- | --- | --- | --- | --- |
| なし（`{}`） | — | 打ったまま | 12 | 2026 |
| `half-num` | `half` | 半角の数字 | 12 | 2026 |
| `wide-num` | `wide` | 全角の数字 | １２ | ２０２６ |
| `kanji-num` | `kanji-digits` | 漢数字を 1 けたずつ | 一二 | 二〇二六 |
| `kanji` | `kanji` | 位取りした漢数字 | 十二 | 二千二十六 |
| `daiji` | `daiji` | 位取りした大字 | 壱拾弐 | 弐千弐拾六 |
| `grouped-num` | `grouped` | 3 けたごとに `,` を入れた半角の数字 | 12 | 2,026 |

数値の項目は活用しない。活用型や送り仮名の始まりのある数値の項目は無効。

### いくつもの書き方

組み込みの関数 `num` は、数をいくつもの書き方で書いた値を返す（[埋め方](placeholder.md#埋め方)）。引数には、上の表の `num` の引数をスペースで区切って並べ、返す書き方とその順を選ぶ。引数がなければ `half wide kanji`。

| 書き方 | 12 で返す値 |
| --- | --- |
| `{num}` | 12・１２・十二 |
| `{num kanji daiji}` | 十二・壱拾弐 |

値ごとに、その書き方の名前を、その値だけを返す引数として添える。`{num}` の １２ の記録は `{num wide}` の項目に付く（[記録](placeholder.md#記録)）。

知らない書き方を引数に含むとき、変換元が数でないときは、値を返さない。

### 位取り

`kanji` は、万・億・兆・京の位で区切って書く（10000 → 一万）。書けないほど大きい数では、その候補は出さない。

### 大字

`daiji` は、`kanji` と同じく位取りし、一・二・三・十を壱・弐・参・拾にする。書けないほど大きい数では、その候補は出さない。

## 変換

- 読みに数があるとき、数を置き場所にした読みで、各辞書の数値の項目を引き（`１こ` → `{}こ`）、表記の置き場所を [埋めた](placeholder.md#埋め方) ものを候補にする。
- かなの数を含みうる読みでは、かなの数を `{kana}` にした読みでも引く（`さんだんかい` → `{kana}だんかい`）。かなの数の区切り方がいくつもあれば、かなの数を 1 つ置き場所にする区切り方は、どれでも引く。2 つ以上置き場所にする区切り方は、少ないほうから、引く数に限りを設けて引く。そのため、かなの数になりうる音が多い長い読みでは、かなの数を 3 つ以上受ける項目に当たらないことがある（`じゅうにねんじゅうにがつじゅうににち` は `{kana}ねん{kana}がつ{kana}にち` に当たらない）。
- `{kana}` の項目から作った候補は、辞書の優先度によらず、同じ読みのほかの候補より後ろに出す（`ごかく` は 互角 が 五角 より先）。
- `{kana}` でない項目も同じ表記を出すときは、どの辞書の項目でも、その表記は `{kana}` でない項目から作った候補として出し、記録する。後ろには回さない（`いっぽん　一本` があれば、`{kana}ぽん　{kanji}本` のほうが安くても、一本 は `いっぽん　一本` の候補として出る）。
- 数を置き換えない読みでも、ふつうどおり引く（`1ばん` という読みの項目があれば、それも候補）。
- 送り仮名を指定したときは、数値の項目を引かない。
- 数だけの読み（`３`）は、組み込みの辞書 `number` が、IME の持つ数の書き方の候補にする（３ → 三）。

数値の項目から作った候補の記録と、数値の項目の辞書登録は、[表記の置き場所](placeholder.md#記録) による。`1こ` で選んだ書き方は、`2こ` を変換したときも効く。
